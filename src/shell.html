        How to read the stage
        
    
        
      
        An eventColor is the key, the number is the event id, the tag below is its event time.
        
      
        Shape is the streamCircles come from the main (left) stream, squares from the right side of a join.
        
      
        Processing timeThe clock and the source tape. "now" is where the reader is.
        
      
        WatermarkAn event-time promise: nothing earlier is expected. Windows close when it passes their end.
        
      
        Checkpoint barrierInjected at the source; each operator saves its state when it passes.
        
      
        Grey, dashed ringGrey: dropped (filtered out or late). Dashed ring: re-read after recovery.
        
      
        Output rowWhat the query emits, with the processing time it was emitted.
